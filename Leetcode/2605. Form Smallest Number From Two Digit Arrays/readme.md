# Algorithm Idea

Approach 1)

Finding the minimum common digit or combining the smallest unique digits from two restricted sets.

Approach 2)

Identifying the smallest shared digit versus the smallest combination of unique digits from two sets.

# Complexity

Approach 1)

- Time: O(nlogn+mlogm)

- Space:O(N+M)

Approach 2)

- Time: O(N + M)

- Space:O(1)
